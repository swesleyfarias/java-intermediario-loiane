# Java Intermediate course exercises - Loiane Groner Course

## About

This repository was created as a continuation of Java Basic course. It contains the exercises I do while studying Java and tracking my progress.
The course covers Enumerations, Java language elements, Multithreading, Strings and Utility Classes.
> **Note:** The course includes exercises only for Enumerations and Multithreading.
